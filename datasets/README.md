# 数据分析课配套数据集

本目录存放 [Python 数据分析](../tutorials/05-data-analysis/01-what-is-analysis.md) 章节使用的 4 份示例 CSV 数据：

- `ledger_2026.csv`：2026 年全年模拟记账记录（干净版）
- `ledger_2026_raw.csv`：含缺失值、异常格式与重复行的原始记账记录（用于数据清洗章节）
- `books.csv`：模拟书店书目表
- `book_reviews.csv`：模拟书店读者评分与评论表

在本地跟随数据分析章节运行代码示例时，将工作目录切换到本目录（或把对应 CSV 复制到脚本同目录）即可直接运行。
